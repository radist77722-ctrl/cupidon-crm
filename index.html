Менеджеры и рейтинг

Планы, часы, заработок, распределение анкет и регистрации

Рейтинг (жёлтая цифра на карточке, 0-100) — среднее трёх метрик примерно поровну: 1) скорость поиска мужчин (от момента, когда анкету взяли в подбор, до 3/3 — считается только рабочее время по сменам, не календарные дни); 2) скорость закрытия анкеты (от взятия в подбор до «Закрыта успешно», тоже по рабочему времени); 3) средняя оценка отзывов. Если по метрике нет данных — она просто не участвует в среднем, никого не топит незаслуженно.

Метрики времени считаются только для анкет, у которых уже зафиксирован момент «взяли в подбор» — это происходит автоматически с сегодняшнего дня. По старым анкетам, где этого момента ещё нет, метрика просто не в счёт.
